 1. [SEO] Unblock Search Indexing & Enable Crawlability (Both Reports)
These are silent blockers. You're likely using either:

A robots.txt that says Disallow: /

A <meta name="robots" content="noindex">

Prompt to fix:

bash
Copy
Edit
Check for any <meta name="robots" ...> tag in index.html. If found, change to:
<meta name="robots" content="index, follow">

Then check for /robots.txt. If it exists, overwrite with:
User-agent: *
Allow: /

Add a sitemap URL if available:
Sitemap: https://riverstickmotors.ie/sitemap.xml
🔧 2. [Best Practices] Add Security Headers to _headers File (Both Reports)
These are invisible but required for higher trust scores:

Prompt:

bash
Copy
Edit
In the Netlify project root, add or update a file called `_headers` with:

/*
  Strict-Transport-Security: max-age=63072000; includeSubDomains; preload
  X-Frame-Options: DENY
  X-Content-Type-Options: nosniff
  Referrer-Policy: strict-origin-when-cross-origin
  Content-Security-Policy: default-src 'self'

This will fix COOP/XFO/CSP audit flags without breaking anything.
🔧 3. [Performance – Mobile Only] Compress and Serve Static Assets Efficiently
You’re seeing TBT and LCP delays from too much JS and image data at once. Don’t change files — just compress and cache them properly.

Prompt:

bash
Copy
Edit
Create a `_headers` file (if not done in step 2) and add:

/*
  Cache-Control: public, max-age=31536000
  Content-Encoding: br
  Vary: Accept-Encoding

This ensures all .html, .css, .js, .webp files are cached and Brotli-compressed.
