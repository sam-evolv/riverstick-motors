### 3. OPTIMIZE ALL HTML FILES

For **EVERY** HTML file in the project, make these modifications:

**A. Add to `<head>` section (after existing meta tags):**
```html
<!-- SEO Meta Tags -->
<meta name="robots" content="index, follow, max-snippet:-1, max-image-preview:large, max-video-preview:-1">
<meta name="googlebot" content="index, follow, max-snippet:-1, max-image-preview:large, max-video-preview:-1">

<!-- Performance Optimization -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="dns-prefetch" href="//fonts.googleapis.com">
<link rel="dns-prefetch" href="//fonts.gstatic.com">

<!-- Mobile Optimization -->
<meta name="theme-color" content="#000000">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="default">
```

**B. Find and preload the LCP (Largest Contentful Paint) image:**
- Scan each HTML file for the largest image that appears above the fold
- Add preload tag for this image in the `<head>`:
```html
<link rel="preload" href="/path/to/lcp-image.jpg" as="image" fetchpriority="high">
```

**C. Optimize ALL `<img>` tags:**
For every `<img>` tag found, add missing attributes:
- If missing `width` and `height`: calculate and add them based on the image file
- Add `loading="lazy"` for images below the fold
- Add `loading="eager"` for above-the-fold images
- Add `decoding="async"` to all images
- Ensure all images have meaningful `alt` attributes

Example transformation:
```html
<!-- Before -->
<img src="image.jpg" alt="Description">

<!-- After (below fold) -->
<img src="image.jpg" alt="Description" width="800" height="600" loading="lazy" decoding="async">

<!-- After (above fold) -->
<img src="image.jpg" alt="Description" width="800" height="600" loading="eager" decoding="async" fetchpriority="high">
```

### 4. OPTIMIZE ASSET LOADING

**A. For all `<script>` tags:**
- Add `defer` attribute to non-critical scripts
- Add `async` attribute to third-party scripts
- Keep critical scripts as-is

**B. For all `<link rel="stylesheet">` tags:**
- Identify critical CSS (likely the main stylesheet)
- For non-critical CSS, implement async loading:
```html

<noscript><link rel="stylesheet" href="non-critical.css"></noscript>
```
