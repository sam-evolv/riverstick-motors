 Fix SEO Blockers: Indexing + Crawlability
These are still present. If this is not fixed, your site will never rank.

Replit Agent Prompt:

bash
Copy
Edit
Search the <head> of index.html for:
<meta name="robots" content="noindex">

If found, replace with:
<meta name="robots" content="index, follow">

Next, check for a file called /robots.txt. If it exists and contains `Disallow: /`, replace it with:

User-agent: *
Allow: /

Finally, ensure there is at least one <a href="/"> link on the homepage with a real URL, not just a hash (#).
✅ Impact: Instant SEO score increase (usually 20+ points)

🔧 4. Fix Image Tags for CLS + Size Hints
Missing width and height on <img> tags damages CLS (Cumulative Layout Shift) — a core metric for SEO and performance.

Replit Agent Prompt:

bash
Copy
Edit
For all <img> tags across the site, add accurate width and height attributes.

Example:
<img src="/images/banner.webp" alt="Banner" width="1600" height="900" loading="lazy">

This does not affect layout due to CSS, but improves layout stability metrics.
✅ Impact: Better LCP, CLS, and SEO audit pass
