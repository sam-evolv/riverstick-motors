 [CRITICAL] Remove "noindex" Meta Tag
Replit Agent Prompt:

bash
Copy
Edit
Search all HTML files (especially index.html) for:
<meta name="robots" content="noindex">

If found, delete it or replace with:
<meta name="robots" content="index, follow">
✅ Impact: Allows Google to index your pages

🔧 2. [CRITICAL] Fix robots.txt to allow indexing
Prompt:

bash
Copy
Edit
At the root of your site, open or create `/robots.txt` and replace its content with:

User-agent: *
Allow: /

Sitemap: https://riverstickmotors.ie/sitemap.xml
✅ Impact: Enables Googlebot to crawl your site fully

🔧 3. [CRITICAL] Make all <a> links crawlable
Prompt:

bash
Copy
Edit
Audit all <a> tags. If any of them use href="#" or are missing href entirely, change them to real URLs (even just "/").

Example:
<a href="#">Contact</a> → <a href="/#contact">Contact</a>
✅ Impact: SEO crawler can now traverse your page

🔧 4. Add a sitemap
Prompt:

bash
Copy
Edit
Create a new file called `sitemap.xml` at the root with this content:

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://riverstickmotors.ie/</loc>
    <priority>1.0</priority>
  </url>
</urlset>
✅ Impact: SEO best practice, helps with indexing in Search Console
